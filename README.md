# MAF Global Solutions - BI & Data Engineering

## 📌 Overview
Enterprise BI migration project for **Majid Al Futtaim**. Migrated workloads to **Microsoft Fabric** using Medallion architecture to deliver scalable, high‑performance analytics solutions.

## 🛠️ Tech Stack
- Microsoft Fabric (Lakehouse, Pipelines, Semantic Models)
- Azure Synapse Analytics
- PySpark on Databricks
- Power BI (DAX, RLS, Incremental Refresh)

## 🏗️ Architecture
Bronze → Silver → Gold layers implemented for scalable data pipelines.

## ✨ Features
- PySpark pipelines for ingestion & transformation  
- Semantic models with Row‑Level Security (RLS)  
- CI/CD deployment pipelines  
- Interactive Power BI dashboards  

## 📋 Responsibilities

### For Fabric Migrated Projects
- Ensured quality, accuracy, and consistency of enterprise data across platforms.  
- Collaborated with business stakeholders to gather requirements and provide accurate effort estimations (ETA).  
- Implemented **Fabric Medallion architecture** (Bronze, Silver, Gold layers) for optimized data flow.  
- Integrated diverse data sources (SQL, Synapse, SharePoint, REST APIs) into the enterprise warehouse.  
- Engineered Fabric pipelines using **PySpark** and **Dataflow Gen2** for ingestion, transformation, and delivery.  
- Designed semantic models in Fabric with **RLS**, connected to Power BI Desktop, and published reports.  
- Maintained and optimized Fabric **CI/CD pipelines** across DEV, UAT, and PROD workspaces.  

### For Non‑Migrated Projects
- Built and managed **Azure Synapse Analytics pipelines, triggers, and data flows** with Blob Storage integrations.  
- Connected Power BI reports using SQL endpoints from Synapse and SharePoint.  
- Performed data transformations using **Power Query Editor** and **Azure Analysis Services**.  
- Designed Power BI models based on **Star, Snowflake, and Galaxy schemas**.  
- Developed DAX measures, calculated columns, KPIs, and implemented RLS in semantic models.  
- Created interactive Power BI dashboards using live connections and DirectQuery.  
- Published and managed reports in Power BI Service, including workspace management and app deployment.  
- Configured scheduled refreshes, incremental refresh, and monitored dataset performance.  
- Developed and optimized SQL queries, joins, views, and stored procedures for reporting workloads.  
- Supported and enhanced existing BI projects, including troubleshooting, performance tuning, and user support.  
- Collaborated with stakeholders to deliver end‑to‑end BI and analytics solutions.
